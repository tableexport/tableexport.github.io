下载与安装

免费版即刻可用，无需注册。装好后点工具栏图标即可识别当前页面的表格。

方式一：商店安装（推荐）

Chrome 应用商店安装 Edge 加载项安装

商店版自动随浏览器更新，无需手动维护。

方式二：官网 CRX 离线安装

如果你无法访问 Chrome 应用商店：

  1. 从 GitHub Release 下载最新的 .crx 文件；
  2. 打开 chrome://extensions/；
  3. 开启右上角「开发者模式」；
  4. 把 .crx 文件拖到该页面即可。

提示：离线版不会自动更新，建议定期检查 GitHub Release 获取新版本。

安装后的下一步

  • 打开任意带表格的网页，点击工具栏的 Table Export 图标；
  • 在候选列表里选中目标表格，预览确认后导出；
  • 需要批量翻页采集？升级 Pro 解锁不限量。
