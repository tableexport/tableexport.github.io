FAQ

How do I use my activation code?

Click the Table Export toolbar icon, go to Settings → Pro / License, paste the code and click Activate.

Does it still work after changing computers or reinstalling?

Yes. The license is yours — paste and activate again, no activation count limit.

Does activation require an internet connection?

No. License codes are verified offline via signatures. The extension itself makes zero network requests.

I lost my activation code. What now?

Contact lslwork666@gmail.com with your payment record and we'll reissue it.

The exported CSV shows garbled text in Excel?

Exports include a UTF-8 BOM and should open cleanly by double-clicking. If you use Excel's data-import wizard, make sure UTF-8 encoding is selected.

What are the free tier limits?

Single-page export is free forever with no row limit. Batch paged collection: 500 rows/day (only rows added from page 2 onward count) and 200 rows per batch run. Pro ($4.99 one-time) unlocks unlimited paging and a 50,000-row limit per batch run.

Can it export lists that aren't <table> elements?

Yes. Div-based repeated blocks (product listings, rankings, dashboards) are detected as exportable pseudo-tables.

Can I get a refund?

If the code fails to activate or was never received, contact us within 7 days with your payment record for a full refund. Activated codes are non-refundable.
