Features

Detects real tables and pseudo-tables

Table Export finds standard <table> elements and div-based repeated blocks (5+ similar sibling nodes): product listings, rankings, dashboard views — including tables rendered by component libraries such as Element Plus and Ant Design. Candidates are highlighted on the page; hover to preview row × column counts, click to select.

Export to CSV, Excel, Markdown, JSON

  • CSV: UTF-8 with BOM — opens cleanly in Excel and WPS, no mojibake.
  • Excel (.xlsx): real spreadsheet files generated via SheetJS.
  • Markdown: paste straight into docs and notes.
  • JSON: feed structured data directly to your programs.
  • Copy to clipboard alongside file download — plain text (tab-separated, pastes straight into Excel), CSV, or JSON — with a pinnable preview grid.
  • The floating toolbar is customizable: switch it off entirely or pick which format buttons show.

Cross-table merge (Pro): tick several tables on the same page and combine them vertically or horizontally into a single export — no more manual stitching.

Merged cells are flattened

rowspan/colspan cells are expanded into clean 2D data on export, so the result works directly in Excel filters and pivot tables.

Batch paged collection

Pick the table, point at the "next" control, and Table Export pages through automatically, merging all pages into one export. Full-page-navigation pagination is supported too — collection resumes automatically after each navigation. Rows duplicated across pages are deduplicated automatically, and the last page is detected so collection stops on its own. Free tier: 500 rows/day. Pro: unlimited.

Fully offline, zero data collected

No network permissions, no requests, no analytics. Even Pro license activation is verified offline with signed codes. See the privacy policy.
