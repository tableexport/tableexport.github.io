Export web tables to Excel / CSV / Markdown / JSON in one click

Turn a selected table or list block into a clean two-dimensional data file — no copy-paste, no scripts.

Four formats for common cases

  • CSV: UTF-8 with BOM, opens without garbled text in Excel or WPS, ready for databases and data cleaning.
  • Excel (.xlsx): a real Excel file generated with SheetJS, structure preserved, ready for reports.
  • Markdown: paste straight into docs and notes when gathering references — no re-formatting.
  • JSON: structured data handed directly to your code.

Cross-table merge (Pro): combine tables into one

Multiple scattered tables on the same page can be merged vertically or aligned horizontally into a single export — split-rendered reports and master-plus-detail tables no longer need manual assembly. This is a Pro feature: upgrade and enable merge mode in the popup.

Preview before export, or just copy

Besides downloading, you can copy the table straight to the clipboard — as text (tab-separated, pastes into Excel with auto columns), CSV, or JSON. The preview grid supports pinning so you can confirm the data before exporting and never grab the wrong table.

Toolbar buttons, customized to your habit

The in-page floating export toolbar can be toggled as a whole or per button — keep only the Excel and CSV buttons you use. Settings sync in real time, and every format button is free.
