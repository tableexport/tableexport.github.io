Fully offline: your data never leaves your browser

Many collection tools upload page data to the cloud. Table Export is the opposite — the extension doesn't request any network permission, so it couldn't phone home even if it wanted to.

Zero data collection, verifiable

  • All table detection, parsing, and export happen locally in the browser;
  • The extension manifest contains no network domain permissions;
  • No data collected, transmitted, or stored — no tracking, no analytics;
  • Verify it yourself: open the browser dev tools Network panel and watch — zero requests during the whole session.

Even paid activation is offline

Pro licenses use offline signature verification — activation never connects to any server. A license can be re-activated on a new computer with no activation-count limit, so it works in intranet and restricted environments too.
