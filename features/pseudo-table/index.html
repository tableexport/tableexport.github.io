核心功能 · Feature

不止 <table>：div 伪表格与列表数据一样能提取

现代网页大量使用 div + CSS 排版数据——商品列表、榜单、后台表格都没有真正的 <table> 标签，普通"表格导出"工具对此无能为力。

重复结构块自动识别

Table Export 会扫描页面中 5 个及以上结构相似的兄弟节点（重复的卡片、行、列表项），把它们识别为可导出的"伪表格"，和标准 <table> 一起列在候选清单里。

  • 电商商品列表、搜索结果列表
  • 排行榜、资讯列表
  • 各类管理后台的数据视图（含 Element Plus / Ant Design 等组件库渲染的表格）

页面上直接高亮选择

候选块会以高亮覆盖层标出，悬停即预览行列数（N × M），点一下选中要导出的块——页面上有多个表格也不会拿错。
