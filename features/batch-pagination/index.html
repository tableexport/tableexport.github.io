核心功能 · Feature

批量翻页采集：自动翻到底，一次导出整站数据

数据分散在几十页里？选好表格、指定"下一页"按钮，Table Export 自动翻页逐页采集，最后合并成一个文件。

两种分页形态都支持

  • 页内切换分页：点击后页面不跳转的常规分页，自动识别翻页按钮连续采集。
  • 整页跳转分页：每页都是新网址的传统分页，支持跨导航续跑——跳转到下一页后自动接续采集，不用人工守着点。

也可以手动指定分页控件，应对页面结构特殊的站点。采集中随时可停，已采集的数据不会丢。

采集过程自动兜底：跨页重复渲染的行会自动去重；翻到末页（按钮还在但没有新数据）会自动识别并停止，不用人工守着。
