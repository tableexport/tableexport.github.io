核心功能 · Feature

网页表格一键导出 Excel / CSV / Markdown / JSON

选中的表格或列表块，一键变成干净的二维数据文件——不用复制粘贴，不用写脚本。

四种格式，覆盖常见场景

  • CSV：UTF-8 带 BOM 编码，用 Excel、WPS 直接打开不会出现中文乱码，适合进数据库或做数据清洗。
  • Excel（.xlsx）：基于 SheetJS 生成真正的 Excel 文件，保留表格结构，交付汇报直接用。
  • Markdown：采集资料写文档、做笔记时直接贴入，无需再排版。
  • JSON：结构化数据直接交给程序处理。

跨表合并（Pro）：多个表格合成一份

同一页面上分散的多个表格，勾选后支持纵向拼接或横向对齐合并成一张表导出——分块渲染的报表、主表加明细表，都不用再手动拼。这是 Pro 功能，升级后在弹窗里开启合并模式即可。

导出前可预览，复制也行

除了下载文件，还支持把表格内容直接复制到剪贴板——文本（制表符分隔，粘贴进 Excel 自动分列）、CSV、JSON 三种格式任选；预览网格支持点击钉住，确认数据无误再导出，避免采错表。

工具栏按钮，按你的习惯定制

页面内的浮动导出工具栏可以整体开关，也可以逐个按钮设置显隐——只留常用的 Excel 和 CSV 也没问题。设置实时同步，所有格式按钮免费可用。
