常见问题

激活码怎么使用？

点击浏览器工具栏的 Table Export 图标，进入「设置 → Pro / 授权」，粘贴激活码并点击激活，看到「Pro 已激活」即成功。

换电脑 / 重装浏览器还能用吗？

能。授权码是你的，重新在设置页粘贴激活即可，无次数限制。

激活需要联网验证吗？

不需要。激活码采用离线签名验证，完全在本地完成，扩展本身不发起任何网络请求。

激活码丢了怎么办？

凭付款记录联系 lslwork666@163.com，核实后补发。

导出的 CSV 用 Excel 打开乱码？

导出的 CSV 已带 UTF-8 BOM，正常情况下 Excel / WPS 可直接打开。若仍乱码，请确认是用「双击打开」而不是通过 Excel 的「数据导入」向导（向导可能强制其他编码）。

免费版有哪些限制？

单页表格导出永久免费、不计量；批量翻页采集每天 500 行（只计自第 2 页起新增的行），单次翻页任务上限 200 行。升级 Pro（¥9.9 一次买断）解锁不限量翻页与单次任务 50000 行上限。

想导出的列表不是 table 标签怎么办？

支持。div 布局的重复结构块（商品列表、榜单、后台数据等）同样会被识别为可导出对象。

付款后多久能拿到激活码？

微信 / 支付宝付款后，将截图发送到 lslwork666@163.com（标题注明「插件付费」），通常几小时内回复，最迟当天。海外 PayPal / 卡支付同样付款后发码，通常几小时内邮件送达。

激活码无法激活或从未收到，7 天内凭付款记录全额退款；已激活使用的情况不支持无理由退款。详见退款政策。
